# LectureAI

LectureAI is a local-first university lecture recorder with multilingual English / Egyptian Arabic / MSA transcription, timestamped audio review, editable study notes, and a Windows Maximum Accuracy workflow.

The Vercel deployment wrapper reconstructs the fixed LectureAI web source from `lectureai-web-essential.tar.gz.b64`, then installs dependencies and builds the app. The packaged source includes the iPhone, iPad, laptop/Windows, microphone-validation, recording-recovery, diagnostics, and multilingual fixes.

Deployment trigger: 2026-08-25.
