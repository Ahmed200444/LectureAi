# LectureAI

LectureAI is a local-first university lecture recorder with multilingual English / Egyptian Arabic / MSA transcription, timestamped audio review, editable study notes, and a Windows Maximum Accuracy workflow.

This repository currently uses a compact deployment wrapper: `lectureai-vercel-source.tar.gz` contains the fixed application source, and the root build script extracts and builds it for Vercel. The source archive includes the iPhone, iPad, laptop/Windows, microphone-validation, recording-recovery, diagnostics, and multilingual fixes.
