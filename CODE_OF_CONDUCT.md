# Code of Conduct

LectureAI welcomes respectful, constructive participation from people with different backgrounds and levels of experience.

## Expected behavior

Participants should:

- discuss ideas and code respectfully
- give specific, useful feedback instead of personal attacks
- assume good faith while still reviewing technical claims carefully
- make room for beginners to ask questions
- protect the privacy of students, speakers, and contributors
- keep disagreements focused on the project and evidence

## Unacceptable behavior

The project does not accept harassment, threats, discriminatory remarks, deliberate disruption, doxxing, or publication of another person's private recordings or personal information without permission.

## Project discussions

Technical criticism is welcome. Explain the problem, provide evidence where possible, and suggest a path forward. Maintainers may edit, hide, lock, or remove contributions that violate these expectations or create a privacy/security risk.

## Reporting conduct problems

If a conduct issue should not be discussed publicly, contact the maintainer through the GitHub profile rather than posting sensitive details in an issue.

By participating in LectureAI's repository, issues, pull requests, or discussions, you agree to follow this code of conduct.
