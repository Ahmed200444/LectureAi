Lecture Recorder

A simpler recording route for iPhone: the recorder runs in Expo Go using Expo's native audio API instead of Safari's MediaRecorder.

1. Install Expo Go 2. Open Lecture Recorder

How to use it

1Install the free Expo Go app from the App Store.

2Return here and tap Open Lecture Recorder. Choose the iPhone / My Device option so it launches in Expo Go.

3Tap Start recording. The recorder keeps the display awake while a lecture is being recorded.

4Tap Finish & save, then choose Save to Files in the iPhone share sheet.

5Import the saved M4A into LectureAI for transcription, notes, translation, and study tools.

Native audio
Uses Expo Audio on iPhone rather than browser MediaRecorder.
High quality
AAC/M4A at Expo's high-quality preset.
Original saved first
The recording is created on-device before you share or import it.
No subscription
The recorder code and Expo Go route do not require a paid plan.

Important iPhone limitation

Keep Expo Go open while recording. Expo Go cannot add Lecture Recorder's own iOS background-audio entitlement, so locked-screen or long background recording is not guaranteed. The recorder deliberately keeps the screen awake to avoid that problem.

A fully standalone iPhone build with guaranteed background recording requires Apple's normal signed-app distribution path. This free route avoids that cost and avoids SideStore/cable setup.

Why this route

It avoids the Safari playback/container issue we encountered, avoids SideStore sign-in, and avoids repeatedly re-signing a free Personal Team build. The actual recording screen runs inside Expo Go as React Native code.
