# Project status

LectureAI Open Source Core is an early-stage project.

## Stable enough to contribute to

- microphone permission/readiness checks
- browser recording with MediaRecorder
- recording timer and microphone-level feedback
- local playback and export
- device/browser diagnostics
- local study notes
- PWA shell support
- automated JavaScript checks and unit tests

## Active roadmap

- multilingual transcription evaluation for English, Egyptian Arabic (Masri), MSA, and mixed technical vocabulary
- timestamp-linked transcript review
- improved iPhone/iPad recording recovery
- stronger accessibility coverage
- broader browser compatibility tests

Project documentation should not represent roadmap items as completed features.
