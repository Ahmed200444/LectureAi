# Open-source maintainer checklist

Before announcing a release or submitting LectureAI to an open-source program:

- [x] MIT license present
- [x] README describes implemented features accurately
- [x] CONTRIBUTING guide present
- [x] SECURITY policy present
- [x] Code of conduct present
- [x] Roadmap and project-status documents present
- [x] Issue and pull-request templates present
- [x] CI validates source and tests
- [x] Current tree blocks common private media and staging archives
- [ ] Repository visibility set to public
- [ ] Repository description/topics configured in GitHub settings
- [ ] Public repository URL verified after visibility change

Metrics and adoption claims should only be added after they are visible and independently verifiable.
