# Verify before public

Final manual checks before switching repository visibility:

1. Open the repository settings and confirm `main` is the default branch.
2. Confirm the current file tree does not contain recordings, credentials, environment files, or archive staging files.
3. Review the repository's historical commits for anything sensitive that should not become public.
4. Set a concise repository description and topics.
5. Switch visibility only when you are comfortable making the full reachable Git history public.
6. After publication, open the public URL in a signed-out browser and verify README, license, issues, and source files are visible.
