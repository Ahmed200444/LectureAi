# Contributor start here

New contributors can begin with the README and CONTRIBUTING guide, then choose a focused issue from the tracker.

Good first contribution areas include:

- browser/device diagnostics
- accessibility and keyboard navigation
- documentation improvements
- regression tests
- PWA/offline behavior
- privacy and local-storage improvements

For larger work such as multilingual transcription or iOS recording recovery, open an issue first so requirements and test cases can be agreed before implementation.
