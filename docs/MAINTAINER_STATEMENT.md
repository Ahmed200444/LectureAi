# Maintainer statement

LectureAI is maintained as an open-source student productivity project focused on reliable browser lecture recording, microphone diagnostics, local-first study notes, and privacy-conscious workflows.

The project intentionally separates implemented functionality from roadmap work. Features such as multilingual automatic transcription are not presented as complete until they are implemented, tested, and measured reproducibly.

Contributions are welcome through issues and pull requests. Security-sensitive reports should follow `SECURITY.md`.
